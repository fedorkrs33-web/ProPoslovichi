# ProPoslovichi — План разработки проекта

## Общая идея

**ProPoslovichi** — облачная энциклопедия пословиц народов мира. Пользователи просматривают каталог пословиц; зарегистрированные пользователи могут добавлять новые записи. Модуль ИИ помогает толковать смысл пословиц с возможностью выбора модели (GigaChat, GPT и др.).

### Ключевые принципы

- **Облачный сервис** — приложение размещается в облаке (Vercel и др.), база данных — в облачном хранилище (Neon, PlanetScale и т.п.).
- **Локальная БД на этапе разработки** — для разработки и тестов используется локальная база (SQLite или локальный PostgreSQL), без обязательного подключения к облачной БД.
- **Аутентификация через Яндекс ID** — вход и регистрация только через «Войти с Яндекс».
- **Доступ к добавлению пословиц** — только для авторизованных пользователей; анонимы только просматривают.
- **Модуль ИИ** — толкование смысла пословицы, культурный контекст, примеры; поддержка нескольких моделей (GigaChat, OpenAI и др.).

## Этапы разработки

### Этап 1. База данных и ядро приложения

**Цель:** стабильная схема БД, локальная разработка, просмотр пословиц без авторизации.

- [ ] **1.1** Зафиксировать схему Prisma:
  - Модель **Proverb** (id, text, language, translation, meaning, origin, createdAt, authorId?).
  - Модели для **NextAuth + Яндекс**: User, Account, Session (по требованиям Auth.js / Prisma Adapter).
  - Связь: у пословицы опционально `authorId` → User (кто добавил).
- [ ] **1.2** Режим БД:
  - Разработка: `DATABASE_URL` → локальная БД (SQLite `file:./dev.db` или локальный PostgreSQL).
  - Production: `DATABASE_URL` → облачная БД (Neon/другое).
- [ ] **1.3** Миграции и seed:
  - Миграции для текущей схемы.
  - Seed: несколько тестовых пословиц (без привязки к пользователям на первом шаге — authorId опционально).
- [ ] **1.4** API и UI:
  - GET `/api/proverbs` — список пословиц (с пагинацией/фильтрами по языку при необходимости).
  - Главная страница: каталог пословиц, карточки, фильтр по языку.
- [ ] **1.5** Убрать или перевести в «заглушки» код, не соответствующий схеме (старые prompts, notes, view-db под несуществующими таблицами), чтобы сборка и запуск были стабильными.

**Результат этапа:** работающее приложение с локальной БД и публичным каталогом пословиц.

### Этап 2. Аутентификация через Яндекс ID

**Цель:** вход и регистрация только через Яндекс; пользователь сохраняется в БД.

- [ ] **2.1** Подключить провайдер **Яндекс** в NextAuth:
  - Документация: [NextAuth.js Providers](https://next-auth.js.org/providers/), OAuth Яндекс.
  - В [OAuth-приложении Яндекса](https://oauth.yandex.ru/) создать приложение, получить Client ID и Client Secret.
  - В `auth.ts`: заменить/добавить провайдер Yandex, оставить PrismaAdapter.
- [ ] **2.2** Переменные окружения:
  - `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`.
  - В README и, при необходимости, в `.env.example` описать настройку Яндекс OAuth.
- [ ] **2.3** Страница входа:
  - Кнопка «Войти с Яндекс» на `/login`, редирект после успешного входа (например, на главную или в личный кабинет).
- [ ] **2.4** Сессии:
  - Стратегия сессий — по возможности «database» (Session в Prisma) для согласованности с облаком и несколькими инстансами.
- [ ] **2.5** Удалить или отключить Google OAuth из конфига, если вход только через Яндекс.

**Результат этапа:** пользователи регистрируются и входят через Яндекс ID, данные хранятся в БД.

### Этап 3. Добавление пословиц зарегистрированными пользователями

**Цель:** только авторизованные пользователи могут создавать и редактировать пословицы.

- [ ] **3.1** Модель данных:
  - В **Proverb** поле `authorId` (опционально) → User; при создании записи заполнять из `session.user.id`.
- [ ] **3.2** API и Server Actions:
  - POST (или Server Action) создание пословицы: проверка `auth()`; запись в БД с `authorId`.
  - PATCH/DELETE (или Server Actions) редактирование/удаление: разрешать только автору или, по решению, модератору.
- [ ] **3.3** UI:
  - Форма «Добавить пословицу» доступна только при наличии сессии; иначе — кнопка ведёт на `/login`.
  - В каталоге: отображать автора (имя/email из User) по желанию.
- [ ] **3.4** Валидация:
  - Обязательные поля: текст, язык; опционально — перевод, толкование, происхождение.

**Результат этапа:** зарегистрированные пользователи добавляют и правят пословицы; анонимы только просматривают.

### Этап 4. Модуль ИИ для толкования пословиц

**Цель:** одна пословица — один запрос к ИИ; ответ: краткое толкование, контекст, примеры; выбор модели.

- [ ] **4.1** Бэкенд ИИ (предпочтительно отдельный сервис, например FastAPI):
  - Эндпоинт, например `POST /analyze`: вход — текст пословицы, язык, идентификатор модели.
  - Выход: структурированный ответ (толкование, культурный контекст, пример употребления, при желании — похожие пословицы).
  - Поддержка нескольких провайдеров/моделей: GigaChat, OpenAI GPT и др. (конфиг или env: какие модели включены).
- [ ] **4.2** Интеграция в Next.js:
  - API Route в приложении, например `POST /api/analyze`, который вызывает ИИ-сервис (внутренний или внешний URL), передаёт ключи из env, возвращает JSON клиенту.
- [ ] **4.3** Безопасность:
  - Ключи к GigaChat/OpenAI только на сервере; лимиты запросов (rate limit) на пользователя/IP, чтобы избежать злоупотреблений.
- [ ] **4.4** UI:
  - На странице пословицы (или в модальном окне): кнопка «Объяснить смысл»; выбор модели из списка доступных; вывод результата ИИ (текст + при желании структурированные блоки).

**Результат этапа:** пользователи получают толкование пословиц от ИИ с возможностью выбора модели.

- [ ] **5.3** ИИ-сервис:

- [ ] **5.4** Документация:

**Результат этапа:** энциклопедия доступна в облаке; разработка по-прежнему ведётся с локальной БД.

## Итоговая архитектура (целевая)

```
[Пользователь]
     ↓
[Next.js (Vercel)]  ←  Яндекс ID (OAuth)
     ↓
[Prisma]  →  [Облачная БД (Neon и т.п.)]   в production
          →  [Локальная БД (SQLite/Postgres)] в разработке
     ↓
[ИИ-модуль]  →  GigaChat / OpenAI / другие модели
```

- **Публичные сценарии:** просмотр каталога пословиц, просмотр одной пословицы, запрос толкования через ИИ (при желании с лимитами для анонимов).
- **Для зарегистрированных:** вход через Яндекс, добавление и редактирование пословиц, использование ИИ с учётом лимитов.
